# Front desk

**You do:** register people, open applications, take documents, answer citizens.

1. **Find before you create.** Search `/owners` by name, phone or ID. The system warns you about likely duplicates. Open the existing person instead of creating a second one.
2. **New application:** `/applications/new` → district, pin on the map (or neighbourhood), plot and old deed numbers → owners with shares that total 100 % → documents → **Submit**. The applicant gets an SMS with the number.
3. **Fees:** after submission the application waits for the fee. The cashier takes it; you don't handle cash.
4. **Returned applications** come back to you with the officer's note. Fix them and submit again.
5. **Citizens asking about a case:** use `/track` with the number and the last 4 digits of their phone, or tell them to dial the USSD code.

**Exercises:** register two people (one already on file), open an application with two co-owners at 60/40, upload a document, submit it.
