# Finance / accountant

**You do:** billing runs, approvals, reconciliation, reports.

1. **Billing run** (`/billing`): choose the period and districts → generate → check totals → submit. A second person approves before bills are issued.
2. **Approvals:** credit notes, payment plans, reversals, cashier differences. You can't approve your own requests.
3. **Reconciliation** (`/payments?tab=reconciliation`): load the provider's statement; lines that don't match a payment are listed for action.
4. **Reports** (`/reports`): revenue, arrears, collection rate and cashiers, with CSV export. The assistant answers questions from the same figures. Check important numbers in the table.
5. **Reminders:** `/messages` → New campaign → overdue reminder. An admin approves it before anything is sent.

**Exercises:** run and approve a billing run on staging, reconcile a sample statement, export the arrears report.
